# 📦 Day 2 - Inventory Tracker

Hey there! 👋  
Welcome to **Day 2** of my **#30DaysOfPythonChallenge**. Today I built a command-line inventory tracker to practice working with variables, naming rules, and data types — the essentials every Python beginner needs.

---

## 📌 What’s This About?
Today’s focus: **Variables, Naming Conventions & Data Types** — understanding how Python stores and organizes data and why using the right naming patterns and types makes your code more reliable.

---

## 💭 Why Does This Matter?
Variables are like containers that hold your data, and the right data type helps Python know how to handle that info. In this project, I created a basic inventory system where each product (as a string) is linked to a quantity (as an integer), all stored neatly in a dictionary.

---

## ✨ Features

Here’s what the app can do:
- ➕ Add new products or update existing stock
- 📋 View the full inventory with types shown for each item
- 🧠 Uses a Python dictionary to organize data efficiently
- 🧪 Type checking to prevent input issues
- 🖥️ Clean, beginner-friendly CLI interaction
